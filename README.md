# CODECRAFT_DS_04

## Task 04 - Sentiment Analysis

### Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards specific topics or brands.

### Dataset
Twitter Entity Sentiment Analysis Dataset

### Work Performed
- Loaded the Twitter sentiment dataset.
- Checked the dataset structure and missing values.
- Removed missing tweets and duplicate records.
- Cleaned the text data.
- Removed URLs, mentions, hashtags, punctuation, and extra spaces.
- Analyzed the distribution of sentiment categories.
- Analyzed sentiment patterns across different entities.
- Compared positive and negative sentiments.
- Performed word-frequency analysis.
- Created visualizations to identify sentiment patterns.

### Sentiment Categories
- Positive
- Negative
- Neutral
- Irrelevant

### Dataset Summary
After data cleaning, 71,656 tweets were analyzed.

### Sentiment Distribution
- Negative: 21,698
- Positive: 19,713
- Neutral: 17,708
- Irrelevant: 12,537
